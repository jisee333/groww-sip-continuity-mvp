Product rationale and measurement

Where AI adds value

A conversational explanation can interpret a user's question against several return periods and the current portfolio snapshot. A static table cannot adapt its explanation to the question or clearly handle uncertainty.

What should remain deterministic

Calculating and displaying verified return percentages should remain deterministic. AI is only the explanation layer; it must never calculate source returns or recommend a fund.

Experiment hypothesis: showing verified 1Y/3Y/5Y return context with a grounded explanation may improve understanding. Validate comprehension and 12-month active-SIP retention in a controlled experiment; do not assume retention impact.

Suggested measures: return-context view rate · comprehension-test accuracy · quality-gate pass rate · AI fallback rate · 12-month active SIP rate. Guardrails: complaints, mistaken interpretation, cancellations and support contacts.
